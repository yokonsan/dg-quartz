语言服务器协议（Language Server Protocol，简称 LSP），定义了编辑器（IDE）和语言服务器之间的通信方式。

- 语言服务器：一个后台进程，能够理解代码，并提供特定于某种语言的功能。实现如方法调用跳转等功能。和客户端通过 [[Cards/永久笔记/JSON-RPC]] 进行通信。
- 语言客户端：编辑器中的一种插件或扩展程序，负责与语言服务器进行通信，获取相应功能并将这些智能特性展示出来。

为什么使用 JSON-RPC？

根据官方设计，LSP 选择 JSON-RPC 的原因是：

1. **简单性**：JSON 格式轻量，易于解析
2. **跨语言支持**：几乎所有编程语言都有 JSON 库
3. **现有库成熟**：JSON-RPC 2.0 有现成的实现库
4. **调试友好**：纯文本格式，可读取日志排查问题
5. **传输灵活**：支持 stdio、socket、named pipes 等多种方式
