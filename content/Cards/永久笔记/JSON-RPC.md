**JSON-RPC 是 [[Cards/永久笔记/RPC]] 的一种具体实现协议**，它明确规定：

-   **数据格式**：必须使用 JSON 文本
-   **传输协议**：通常使用 HTTP，但也可以使用 TCP、[[Cards/永久笔记/WebSocket]] 等
-   **消息结构**：必须包含 `jsonrpc`、`method`、`params`、`id` 等字段

**特点**：

-   ✅ **简单易读**：纯文本 JSON，调试方便（curl 就能调用）
-   ✅ **跨语言**：所有语言都支持 JSON 解析
-   ✅ **无状态**：基于 HTTP，天然支持无状态服务
-   ❌ **性能低**：文本序列化 + HTTP/1.1 开销大
-   ❌ **功能弱**：无流式调用、无连接复用等高级特性

**JSON-RPC 的真实使用场景：**

-   **区块链钱包**：MetaMask 与 DApp 通信（浏览器插件）
-   **跨语言脚本**：Python 脚本调用 Go 写的服务（简单轻量）
-   **老旧系统**：早期的一些内部工具 API

## 协议规范

一个标准的 JSON-RPC 2.0 请求：

```json
{
  "jsonrpc": "2.0",        // 协议版本
  "method": "add",          // 调用的方法名
  "params": [1, 2],         // 参数（数组或对象）
  "id": 12345               // 请求ID，用于匹配响应
}
```

响应：

```json
{
  "jsonrpc": "2.0",
  "result": 3,              // 返回结果
  "id": 12345               // 对应请求的ID
}
```
